Netflix Dataset - Exploratory Data Analysis (EDA)

Objective

Perform Exploratory Data Analysis (EDA) on the Netflix dataset to identify trends and insights.

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

Dataset

Netflix Titles Dataset

Analysis Performed

- Data inspection using info() and describe()
- Missing value analysis
- Release year distribution
- Movies vs TV Shows comparison
- Top countries analysis
- Rating distribution analysis
- Correlation heatmap

Key Findings

1. Most Netflix content was released after 2010.
2. Movies are more common than TV Shows.
3. The United States contributes the highest number of titles.
4. TV-MA is the most frequent content rating.
5. Missing values exist in director, cast, and country columns.

Conclusion

Netflix has grown rapidly in recent years, with movies dominating the platform and TV-MA being the most common rating category.
